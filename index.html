怎么装

📱 Android · APK 装机
  1. 用 Chrome / Edge / Firefox 等浏览器打开本页 —— 微信内置浏览器装不上,会自动屏蔽 APK,长按链接"在浏览器打开"。
  2. 点上方"Android"按钮下载 APK。
  3. 下载完成后点开 APK 文件。
  4. 系统提示"未知来源"或"此应用可能有害" —— 选"仍要安装"/"允许安装"。
  5. 装完打开纸鸢,或在文件 app 里选一份 .md 文件 → 打开方式 → 纸鸢。
💻 Windows · 安装版
  1. 点击上方"Windows · 安装版"下载 PaperiteSetup-1.0.0.exe。
  2. Windows Defender 可能提示"未识别的发布者" —— 点"更多信息" → "仍要运行"。
  3. 跟着安装向导一路下一步。
  4. 开始菜单找到纸鸢 → 打开后用菜单选 .md 文件。
📦 Windows · 便携版(不想装就用这个)
  1. 下载 zip 包,解压到任意目录。
  2. 双击文件夹里的 paperite.exe 启动 —— 无需安装,绿色便携。
